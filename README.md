# BMI Calculator
A simple, user-friendly application designed to calculate Body Mass Index (BMI) based on user input (weight and height).
## Tech Stack
* **Language:** Python
## How It Works

The application uses the standard BMI formula:

$$BMI = \frac{weight\ (kg)}{height\ (m)^2}$$

### BMI Categories

| BMI Range | Category |
| :--- | :--- |
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal weight |
| 25.0 – 29.9 | Overweight |
| 30.0 and above | Obesity |
